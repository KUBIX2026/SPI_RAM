# SPI-RAM

Almacenamiento de información respecto al proceso de creación del dispositivo de la consola y desarrollo conceptual de las etapas tempranas del diseño general del dispositivo.

La creación de los diagramas se hizo mediante código "mermaid" con asistencia de Gemini by Google para la sintaxis pero de diseño propio, se crean dos archivos cuando aplique; uno para visibilidad del código y el otro para visibilidad de la gráfica. Pará mejorar visibilidad se usan formatos estandarizados de imagen .PNG .PDF o edición directa de los archivos dentro del .md. Se indica en cada caso cuál corresponderá para efectos de visibilidad.

Para información respecto al procedimiento del controlador para la RAM ir a [spiram_ctrl.v](/spiram_ctrl), para información relevante de la propuesta del flujo de la consola ir a [Main Flowchart](/Main%20Flowchart) y para la propuesta de diseño referenciar [Console Design](/Console%20Design).
